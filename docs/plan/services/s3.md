# S3

## Crates & scope

- Crates: `aws-sdk-s3`; `aws-sdk-cloudwatch` for bucket size
- Scope: **per item**. `ListBuckets` is account-wide, but each bucket lives in one
  region, and object calls must go to that region.

## Resource kinds

| Kind | Aliases | List | Describe |
|---|---|---|---|
| `s3:bucket` | `s3`, `bucket` | `ListBuckets` (paginated; returns `BucketRegion`) | `GetBucketVersioning`, `GetBucketEncryption`, `GetPublicAccessBlock`, `GetBucketPolicy`, `GetBucketLifecycleConfiguration`, `GetBucketTagging` (each fetched in parallel; a failure in one doesn't block the others) |
| `s3:object` | (drill-in only) | `ListObjectsV2` with `Delimiter="/"` | `HeadObject` |
| `s3:version` | (`v` on object) | `ListObjectVersions` | |

## Main view: the Miller-column browser

```
 buckets          │ logs-prod/        │ 2026-10-12/        │ preview: app.json
 assets-cdn       │ ▸2026-10-13/      │  app.json   12 KB  │ {
▸logs-prod        │  2026-10-12/      │  err.log   340 KB  │   "level": "info",
```

- Each column is one level of prefixes, so `l`/`→` drills in and `h`/`←` goes back.
- Path bar: typing `s3://bucket/some/prefix/` jumps straight there.
- **Preview** pane (fetches only a byte `Range`, the first 64 KB):
  - text, JSON (pretty-printed), CSV (as a table), and Parquet (schema only)
  - `.gz` is decompressed on the fly
  - images show metadata only
  - binary files show a hex dump

## Columns

- **Buckets:** `NAME` · `REGION` · `CREATED` · `SIZE` (from CloudWatch, lazy) · `PUBLIC?`
- **Objects:** `KEY` · `SIZE` · `LAST MODIFIED` · `STORAGE CLASS`

## Actions

| Key | Action | API | Safety | CLI |
|---|---|---|---|---|
| `D` | Download (file or prefix, recursive) | `GetObject` | safe | `aws s3 cp s3://{b}/{k} .` |
| `U` | Upload (file picker / path prompt) | `PutObject` / multipart | mutating | `aws s3 cp {path} s3://{b}/{prefix}` |
| `p` | Presigned URL (TTL prompt, copied to clipboard) | `presigned()` on `GetObject` | safe | `aws s3 presign s3://{b}/{k}` |
| `o` | Open in `$PAGER` / default app (downloads to temp) | `GetObject` | safe | |
| `v` | Versions | `ListObjectVersions` | safe | |
| `Del` | Delete object(s) / prefix | `DeleteObjects` (batches of 1000) | destructive | `aws s3 rm s3://{b}/{k}` |
| `x→copy` | Copy/move to another key or bucket | `CopyObject` | mutating | `aws s3 cp/mv` |

- `Space` multi-selects.
- Bulk downloads and uploads run as background jobs with a progress bar in the
  status line, and can be cancelled.

## Relations

- bucket → CloudFront distributions using it as an origin
- bucket → Lambda functions triggered by it (`GetBucketNotificationConfiguration`)
- bucket → its KMS key (from encryption settings)
- bucket → its access-log bucket

## IAM permissions

- **Read:** `s3:ListAllMyBuckets`, `s3:ListBucket`, `s3:ListBucketVersions`, `s3:GetObject`, `s3:GetBucket*`, `cloudwatch:GetMetricData`
- **Write:** `s3:PutObject`, `s3:DeleteObject`, `s3:DeleteObjectVersion`

## Gotchas

- **Bucket size:** don't compute it by listing objects. Use the CloudWatch
  `BucketSizeBytes` / `NumberOfObjects` metrics; they're daily, so show "as of
  yesterday".
- Upload: the Rust SDK has no high-level transfer manager in the main crate. Write a
  small multipart helper, or check whether the `aws-s3-transfer-manager` crate is
  ready to use.
- Buckets whose policy denies the caller will show AccessDenied in their sub-views.
  That's per bucket: show the error and keep the rest of the list working.
- Object keys can contain characters that need escaping in the CLI command; quote
  them correctly in `cli_template`.
- Directory buckets (S3 Express) use `ListDirectoryBuckets`; they're out of scope
  for v1.
